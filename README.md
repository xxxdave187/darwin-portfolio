# Darwin | Portfolio Website (Redesign)

A dark, editorial-style personal portfolio for Darwin, a Full-stack Web Developer.
Built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

## Open this in VS Code
1. Open this folder in VS Code (File > Open Folder)
2. Install the "Live Server" extension (optional but recommended)
3. Right-click `index.html` -> "Open with Live Server"
   (or just double-click `index.html` to open it in your browser directly)

## Structure
- `index.html` — page markup
- `style.css` — all styling (colors, layout, animations)
- `script.js` — interactivity (custom cursor, typing effect, tabs, scroll reveal, mobile menu, contact form)
- `images/` — your photo and project screenshot
- `favicon.svg` — browser tab icon

## Features
- Custom circular cursor (desktop only, auto-disabled on touch devices)
- Typing effect and blinking "available" status dot
- Scroll-reveal animations
- Tilting hero ID card
- Scrolling marquee ticker
- Projects / Tech Stack tab switcher
- Mobile hamburger menu
- Contact form that opens your email app with the message pre-filled
